## 发布与自更新

1. 应用版本在 `app/build.gradle.kts` 的 `versionCode` / `versionName`，当前 **0.2.0（code 2）**。
2. 在 GitHub 创建 Release，tag 使用 `v0.2.0`，上传 `app-debug.apk`（或 release APK）与同名 `.sha256` 文件。若 Release 资产自带 `digest`，应用也会读取。
3. App 的「关于与更新」默认仓库为 `JUANWANG-BUAA/kestrel-ledger`，可在页面内改成任意 `owner/repo`；检查顺序是 GitHub 官方 API → gh-proxy → ghproxy.net → ghfast。
4. 下载后校验大小与 SHA-256，再比对 APK 签名证书；不一致会删除安装包并拒绝安装，避免系统强制卸载导致账本丢失。
5. 安装通过 `FileProvider` + 系统安装器，只替换程序；账本、缓存与偏好留在应用数据目录。升级前建议在「持仓 → 导出备份」保留一份加密备份。
6. 调试包与正式包签名不同：如果从 GitHub 下载的是另一签名构建，应用会拒绝；要自更新，需统一签名（或用同一 debug 签名构建发版）。
