## 0. 一句话定位

**一个"本地优先"的个人基金/黄金/指数资产看板**：把你散落在支付宝、天天基金、券商、银行里的持仓汇总到小米手机本地，自动核算真实收益率，盘中实时估算当日盈亏，并长期沉淀你自己的净值库与持仓历史。

**不是**：荐基荐股平台、交易下单工具、投顾服务。

**两个使用场景**
1. **我的钱**：持仓、成本、收益、盘中估算、黄金克重。
2. **我的眼**：全球市场（大盘/科创/美日韩欧）、个股查询、板块热点、图表对比、每日简报。

## 1. 竞品分析与差异化

| 产品 | 现状 | 短板 |
|---|---|---|
| 养基宝 | 持仓同步 + 收益统计 | 需登录授权、数据在云端、估值能力弱、黄金缺失 |
| 支付宝/天天基金 | 自家持仓 | 只管自家，跨平台无法合并；收益口径不透明 |
| 同花顺/雪球 | 行情强 | 场外基金记账弱、无穿透估算、广告多 |
| 且慢/蛋卷 | 组合分析 | 偏投顾导向、非本地 |
| Excel/自建脚本 | 完全可控 | 无实时估值、无移动体验 |

**本产品 7 个差异化点**

1. **本地优先**：持仓、流水、成本全部只存在手机（SQLCipher 加密），默认不上云，无需账号。
2. **自研估值引擎**：官方"盘中估值"接口已不可用（实测 `FundVarietieValuationDetail` 返回空），本产品用「重仓股穿透 + 历史回归 + 偏差自学习」自算，并输出**置信区间**与**历史精度**。
3. **口径透明**：同时给出持有收益、累计收益、TWR、XIRR，每个数字都能点开看公式和原始流水。
4. **黄金全链路**：**浙商银行积存金报价（含买卖点差）** + 上金所 AU9999 + 伦敦金/纽约金 + 金 ETF + 美元汇率，统一为「元/克」口径，支持人民币折算与内外盘溢价对比。
5. **全球市场一站通**：A 股（含**科创板/北交所专区**）、港股、**美股、日股、韩股、台股、欧股**的指数与个股查询，K 线/分时可视、可叠图对比、可总结成简报。
6. **银行金价可比**：把银行渠道金价（浙商银行）与交易所金价放在同一坐标系，算得清点差与溢价，也看得清"我买的贵了多少"。
7. **长期数据自持**：可回填单只基金 20 年历史净值，季度重仓历史本地留存，支持任意时点回看与回测。

## 4. 功能详述

### 4.1 持仓同步（4 条通路，按可靠性排序）

| 通路 | 说明 | 准确度 | 合规风险 | 版本 |
|---|---|---|---|---|
| A. 手动记账 | 输入买入金额/份额/净值/日期 | 100% | 无 | P0 |
| B. 截图 OCR | 用户截支付宝/天天基金持仓页 → ML Kit 中文识别 → 结构化 → 人工确认 | 95%+（人工二次确认） | 低（用户主动提供） | P0 |
| C. 文件导入 | CSV/Excel 账单（支付宝「账单导出」、天天基金导出、券商对账单） | 99% | 低 | P0 |
| D. 账号直连 | 模拟登录第三方平台抓取 | 高 | **高，无授权、违反用户协议、有风控封号风险** | **不做** |

> 设计立场：**永远不做 D**。这也正是养基宝类产品的风险点与法律灰区，本产品以"用户自持数据"规避。

**OCR 流程**

```
截图 → 图像预处理(裁切/二值化) → ML Kit Text Recognition v2 (中文)
     → 版式解析器(模板库: 支付宝/天天基金/蛋卷/券商)
     → 候选持仓/流水列表 → 差异检测(与已有持仓比对，识别"新增加仓")
     → 用户确认页(逐项勾选/改错) → 事务写入
```

要点：
- 模板库用「锚点关键字 + 相对位置」而非绝对坐标，兼容分辨率与 App 改版
- 每次导入生成 `import_batch`，可整批撤销
- 识别不确定项标黄，强制人工确认，绝不静默写入
- 增量语义：识别到的累计持仓与本地持仓对比 → 生成"加仓差额"流水（US-02）

### 4.2 交易流水与成本核算

**流水类型**：`BUY / SELL / DIVIDEND_CASH / DIVIDEND_REINVEST / SWITCH_IN / SWITCH_OUT / SUBSCRIBE_FEE / SPLIT / TRANSFER_IN / TRANSFER_OUT / FEE / CASH_IN / CASH_OUT`

**成本计算双口径**

| 口径 | 算法 | 用途 |
|---|---|---|
| 移动加权平均（默认） | 每次买入更新 `avg_cost = (原成本额 + 本次金额 + 手续费) / 总份额`；卖出不改变 `avg_cost`，只减份额 | 与支付宝/天天基金展示口径一致 |
| 先进先出 FIFO（可选） | 维护 lot 队列 | 更符合税务直觉、可算持有期 |

**分红处理**：现金分红单独记录（不冲减成本，计入累计收益）；红利再投按当日净值新增份额。**份额确认**：场外基金 T 日 15:00 前申购按 T 日净值，份额 T+1 确认——在途资金用 `pending_txn` 状态表达，UI 显示"确认中"。

**一致性保证**：流水是唯一真相（source of truth），持仓永远可重算。提供「重算全部持仓」按钮与每日自检任务（校验 `sum(txn) == position`）。

### 4.3 收益计算（口径透明）

| 指标 | 公式 | 备注 |
|---|---|---|
| 持仓市值 | `shares × latest_nav` | 在场内用实时价，场外用净值/估算净值 |
| 持有收益 | `市值 - 成本额` | 口径同上 |
| 当日收益 | `shares × (NAV_t - NAV_{t-1}) + 当日卖出已实现 + 当日现金分红` | 盘中用估算值 |
| 累计收益 | `持有收益 + 已实现收益 + 累计现金分红` | |
| 持有收益率 | `持有收益 / 成本额` | |
| 时间加权 TWR | 按现金流切分子区间，几何连乘 | 衡量"基金选得好不好" |
| 资金加权 XIRR | Newton 迭代解 `Σ CF_i/(1+r)^{(d_i-d_0)/365} = 0` | 衡量"我的操作赚不赚钱" |
| 最大回撤 | 基于组合每日净值序列（用快照重建） | |
| 波动率/夏普 | 日收益年化 σ×√250 | 无风险利率可配置（默认 1.5%） |

> **关键设计**：每天收盘后写一条 `portfolio_snapshot`，这是长期数据的地基——没有快照就没有回撤、没有历史回看、没有 TWR。

### 4.4 盘中估值与收盘预估（核心，详见 `docs/03-估值预测算法与数据模型.md`）

- **盘中估值**：交易时段每 60s 更新，展示预估涨跌幅与预估净值
- **收盘预估（15:00 定格）**：A 股收盘后给出当日预估净值（QDII/港股延时项标注）
- **净值公布后**：自动回填真实净值 → 计算残差 → 更新偏差校准参数 → 更新精度面板
- **可信度**：显示 `±1.96σ` 区间与"近 20 日平均误差 x.xx%"，用户可判断能不能信
- **绝不**使用"预期收益""保证"等表述，统一叫「净值估算（非官方）」

### 4.5 行情中心

- 基金：搜索（代码/拼音/名称）、净值曲线、规模、经理、费率、同类排名、持仓
- 指数：上证、深成、沪深300、中证500、创业板、恒生、纳指、标普
- 板块：东财行业/概念板块列表（实测 496 个）、板块成分股、板块对应基金
- 股票：重仓个股实时行情（用于归因）
- 黄金：AU9999（上金所）、伦敦金 XAU、纽约金 GC、沪金主力、黄金 T+D、518880 等 ETF、USDCNY
- 每个标的可「加入自选」，自选列表支持分组与排序

### 4.6 黄金模块（差异化，❖ 已实测精度）

> **实测结论**（详见 `docs/07` 第三部分）：黄金 ETF 联接基金是全品类中**最容易估准**的——
> MAE **0.069%**、R² **99.5%**、方向命中 **98.8%**（挂钩上金所 AU9999）。
> 场内黄金 ETF 直接用实时价，**无需估算**，但必须展示折溢价。

### 4.6 黄金模块（差异化）

| 视图 | 数据 | 说明 |
|---|---|---|
| 人民币克价 | `118.AU9999` | 国内实际成交价，最贴近实物金 |
| 国际金价折算 | `XAU(USD/oz) × USDCNY ÷ 31.1034768` | 理论平价 |
| 内外盘溢价 | `上海金 - 折人民币金价`，以及溢价率 | 反映国内需求/汇率管制 |
| 时间序列 | 三条曲线同图，可切换 | 支持 1D/1W/1M/1Y/全部 |
| 持仓联动 | 黄金 ETF / 纸黄金持仓折算为"克数"与"克成本" | 例如"你等于持有 12.4 克黄金，克成本 842 元" |
| **浙商银行金价** | 买入价/卖出价/点差（OCR 校准或点差模型，详见 4.13） | 银行渠道实际可交易价，与交易所价对比可见溢价 |
| 相关性 | 沪金与组合相关性、与沪深300 相关性 | P2 |

### 4.7 长期数据保留

- 净值库：任一基金可回填全部历史（`f10/lsjz` 分页，单基金 20 年约 5000 行）
- 季报历史：每次披露的十大重仓 / 资产配置 / 规模，按报告期保留（**估值回测的必需品**）
- 组合快照：每日一条（保留 10 年 ≈ 3650 行/账户，极小）
- 交易流水：永久保留，附带 `import_batch` / 修改历史（软删除 + 审计）
- 估值历史：每次估算落库（可聚合降采样：1 分钟 → 收盘后压缩为当日高低/均值/残差）
- 导出：`xlsx + json + sqlite` 加密压缩包，一键备份，可在新机恢复

**去抖与升级触发（估值提醒能否可用的核心，算法见 `03` §B.10）**

```
触发需同时满足 5 个条件：
① 幅度   |est| ≥ threshold
② 显著性 |est − threshold| ≥ 1.0 × σ      ← 超出量必须大于估值噪声
③ 持续性 连续 3 次采样（约 90s）均满足 ①②
④ 冷却   距上次同规则触发 ≥ 30 min
⑤ 配额   单规则 ≤ 3 次/日；全局 ≤ 8 条/日
时段：仅在该标的市场时段；静默时段默认 22:00–08:00（金价夜盘可单独开）
升级：冷却期内若突破 2×threshold，允许越冷却再触发一次（计入配额）
```

> ② 是关键：没有显著性检验，估值噪声会导致"每天都报警"，用户两天就关通知。

**通知文案规范（合规硬性要求）**

```
❌ 错误：易方达优质精选 今日下跌 2.34%
✅ 正确：〔估值提醒〕易方达优质精选 110011
        估算 −2.34%（4.0062 → 3.9120）｜已超阈值 −2.00%
        连续 3 次确认｜估值误差 ±0.21%｜14:32
        重仓穿透估算 · 非官方净值 · 仅供参考
```

- 任何估算类通知**必须**出现「估算」「非官方」字样与误差值
- 禁止出现"建议/应该/即将上涨/可低吸"等表述
- 金价通知必须标注来源（上金所官方 / 伦敦金折人民币 / 银行报价-截图校准）

**通知频道**

| 频道 | 重要性 | 用途 | 限频 |
|---|---|---|---|
| 实时动态（Live） | HIGH（无声、不打断） | 灵动岛/焦点通知常驻卡片（§4.14） | 更新节流 30s |
| 行情提醒 | DEFAULT | R1–R8 | 见上述配额 |
| 净值 | DEFAULT | R9 | — |
| 计划 | DEFAULT | R10 | — |
| 日报 | LOW | 每日汇总 | 1 条/日 |

**通知诊断**：设置页保留最近 20 条触发记录（时间 / 命中条件 / 是否被系统拦截 / 是否静默），用户可自查"为什么不响"。

> MiPush 有配额与资质限制，**首选本地通知**；灵动岛实现见 §4.14。

### 4.12 市场总结与简报（Market Summary）

**目标**：每天自动产出「今天市场发生了什么 + 我的持仓为什么涨跌」的中文简报。

**三层实现（渐进增强，无 LLM 也完整可用）**

| 层 | 名称 | 说明 | 依赖 |
|---|---|---|---|
| L1 | 事实抽取（离线） | 涨跌家数、成交额与环比、领涨/领跌板块 Top5、全球指数、金价与溢价、持仓贡献 Top5、估值误差 | 纯本地计算 |
| L2 | 模板叙述（离线） | 把 L1 事实按行情体裁组织为段落，支持词库（缩量下跌/放量反弹/普跌/二八分化） | 本地模板 |
| L3 | LLM 摘要（可选，默认关） | 用户填自己的 API Key（DeepSeek/通义/本地模型），**只把 L1 结构化事实作为上下文**，输出自然语言 | 用户自选 |

**合规护栏（硬约束）**
1. 上下文只喂事实，不喂观点；系统提示词禁止输出买卖建议、目标价、看多看空。
2. 输出后置过滤：命中违禁词表（建议买卖/必涨/抄底/梭哈/目标价）→ 丢弃并降级为 L2 模板输出。
3. 默认**脱敏模式**：不把持仓金额/份额传给模型，只传涨跌百分比与结构。
4. 每篇简报固定页脚：「数据整理，非投资建议」。

**简报骨架示例**

```
【2026-10-15 收盘简报】
大盘：上证 3707.48（-1.59%）失守 3720；深成 11816.79（-2.43%）；科创50 跌幅居前。
情绪：两市成交 1.23 万亿，较昨日放量 8%；上涨 812 家 / 下跌 4306 家。
板块：卫浴电器 +4.57% 领涨，纺织鞋类制造 +3.38%；半导体、白酒走弱。
海外：纳指 -1.88%，日经 -4.90%，韩国KOSPI -7.57%。
黄金：AU9999 892.96 元/克（-0.17%）；伦敦金折人民币 894.18；内外盘溢价 -1.22 元。
我的持仓：估算 -0.42%（-538 元）。拖累：易方达优质精选 -1.15%；贡献：黄金ETF +0.31%。
提示：3 只持仓为估算值，近 20 日平均误差 0.21%。
```

**周报/月报**：收益归因、行业暴露变化、重仓股重合度变化、与基准对比、操作复盘（XIRR 与 TWR 的差异解释）。

### 4.13 浙商银行金价（银行渠道金价）

**实测结论**：浙商银行个人贵金属业务为「**财富金积存（积存金）**」「财富金」「代销实物贵金属」，但**官网无公开实时报价接口**（仅有产品介绍页，报价只存在于手机银行 App / 网银）。

**四路获取策略（按优先级）**

| # | 方案 | 实现 | 精度 | 稳健性 | 阶段 |
|---|---|---|---|---|---|
| 1 | 官方接口适配 | S0 用 mitmproxy/Charles 抓一次 App/小程序，定位报价端点与鉴权，写成适配器 | 完全一致 | **低**：银行风控严、需登录态、有封号风险 → 仅低频（≤1 次/15min，且仅用户打开页面时） | S0 探针后决策 |
| 2 | **截图 OCR 校准** | 用户截报价页 → ML Kit 识别买入/卖出价 → 写入手动报价，当日有效 | 完全一致 | **高**（用户主动，零风控） | P0 |
| 3 | **点差模型折算** | `浙商价 ≈ AU9999 × (1 + 点差率)`，点差率由方案 1/2 的历史样本拟合（初始参考 0.3%~1% 或 0.5~1.5 元/克） | 中（±0.5 元/克） | 高（纯本地） | P0 |
| 4 | 手动录入 | 用户输入日报价作为当日基准 | 完全一致 | 高 | P0 |

**展示设计（黄金页 · 银行金卡）**

```
┌────────────────────────────────────────────┐
│ 浙商银行 财富金积存          13:05 更新 ⟳  │
│  买入价  894.20 元/克   ▲ +1.30  (+0.15%)  │
│  卖出价  891.60 元/克   点差 2.60 元/克     │
│  来源：截图校准（10-15 12:41）     [校正]    │
│  ── 对比 ──                                  │
│  上金所 AU9999    892.96   -0.17%            │
│  伦敦金折人民币   894.18   +0.28%            │
│  溢价（沪 - 折）  -1.22 元/克               │
│  ── 我的持仓 ──                              │
│  积存金 12.40 克 / 克成本 842.30 / +6.16%    │
└────────────────────────────────────────────┘
```

**建模要点**
1. **点差必须建模**：银行买入价 > 卖出价，**估值用卖出价**（可变现口径），否则高估资产。
2. **费用建模**：积存金常有持有期/赎回费、提金费，存 `bank_gold_product` 表，用于算「净可变现价值」。
3. **来源必须标注**：实时接口 / 截图校准 / 模型折算 / 手动录入，用不同角标区分，杜绝"看起来像实时"。
4. **历史序列**：每日最后一次采集值写入 `instrument_daily_bar`，与 AU9999 做走势对比、监控点差漂移。
5. **稳健优先**：方案 1（抓包）只在 S0 验证可行且无风控风险时启用，否则永久以 2/3/4 为主路径。

### 4.14 灵动岛 / 焦点通知 / Live Updates

**目标**：把"今日持仓涨跌"与"金价"以常驻实时卡片形式挂在状态栏（类 iOS 灵动岛），不打开 App 也能一眼看到。

**三条实现路径（按可用性排序）**

| 路径 | 机制 | 依赖 | 覆盖 | 阶段 |
|---|---|---|---|---|
| **A. Android 16 Live Updates（主路径）** | `Notification.ProgressStyle` + `setRequestPromotedOngoing(true)`，系统在状态栏/锁屏以胶囊 + 展开卡片呈现 | Android 16（API 36）原生；**无需小米特批、无需服务端** | HyperOS 3（Android 16 基座）及以上 | P0 |
| **B. HyperOS 焦点通知（增强）** | 小米私有：MiPush 消息 + `miui.focus.*` extras，需向小米申请「焦点通知」权限 | 企业开发者资质 + 小米侧开通 + **服务端推送** | HyperOS 1~3 | P1（可选） |
| **C. 常驻通知兜底（保底）** | `setOngoing(true)` + 进度条/大文本样式，HyperOS 可置顶 | 无 | Android 8+ 全部 | P0 |

> 路径 A 在 HyperOS 上是否直接渲染为"灵动岛"样式，**需 S0 真机验证**（命令见 `02` §A.7）。未打通则自动降级到 C，**功能不缺失**（只是不炫）。这是有意识的架构选择：核心提醒能力不绑定小米私有通道。

**卡片内容设计**

```
收起态（状态栏胶囊）  [ ● −2.34%  易方达优质精选 ]

展开态（卡片）
┌────────────────────────────────────────────┐
│ 易方达优质精选 (QDII)          14:32  ⟳    │
│   估算 −2.34%     4.0062 → 3.9120          │
│   ≈ −¥842         估值误差 ±0.21%           │
│  ── 触发 ──                                 │
│   已跌破 −2.00% 阈值（连续 3 次确认）        │
│  ── 主要拖累 ──                              │
│   腾讯控股 +3.31% / 贵州茅台 +1.02%          │
│   重仓穿透估算 · 非官方净值 · 仅供参考         │
│                    [ 查看详情 ]   [ 关闭 ]   │
└────────────────────────────────────────────┘
```

**生命周期状态机**

```
IDLE
 └─(规则触发)→ SHOWING ─(每 ≥30s 且变化 ≥0.1%)→ SHOWING（原地更新）
                 │
                 ├─(15:00 收盘)──────────→ SETTLED（定格收盘估算）
                 │                            └─(净值公布)→ FINISHED（3 min 后自动消失）
                 ├─(用户点"关闭")────────→ FINISHED
                 └─(超时 4 小时)─────────→ FINISHED（防僵尸通知）
```

**多规则合并**：同时命中多只基金 → 合并为一条 `〔持仓提醒 (3)〕`，展开显示列表。系统对 promoted ongoing 的并发数有限制，**必须合并**；金价单独一条（不同语义，不混）。

**节流与功耗**
- 更新节流：≥30 s **且** 涨跌幅变化 ≥0.1% 才刷新（秒级刷新会被系统限流且耗电）
- 仅当存在 active live activity 时才保持后台 60 s 采样循环；`FINISHED` 立即释放前台服务
- 屏幕关闭时降频到 5 min（除非用户设为"盯盘模式"）

**权限与引导**
1. `POST_NOTIFICATIONS`（Android 13+）
2. Android 16：`NotificationManager.canPostPromotedNotifications()` 为 false → 引导到 `Settings.ACTION_MANAGE_APP_PROMOTED_NOTIFICATIONS`
3. 小米省电策略「无限制」（否则更新延迟）
4. HyperOS 支持「通知置顶」时提示用户置顶

**S0 真机探针（必做，产出结论写入 `02` §A.7）**

```bash

adb shell dumpsys notification_manager | grep -iE "promoted|live|progress"
# 2) 抓真实 App 的焦点通知 extras（HyperOS 上找系统应用：音乐/高德/美团）
adb shell dumpsys notification --noredact | grep -iE -A30 "miui.focus|focus_param|focus.param"
# 3) 自己发一条 promoted ongoing，看是否出现在状态栏胶囊/锁屏实时区
#    验收：能看到胶囊 + 展开卡片 → 路径 A 可用；否则记录降级到路径 C
```

### 6.3 缓存与限流策略（防封禁，重要）

| 数据 | 频率 | TTL | 备注 |
|---|---|---|---|
| A 股盘中行情/指数/板块 | A 股时段 6~15s（仅前台/有小组件） | 3~5s | 批量合并一次请求 |
| **海外指数（美/日/韩/欧）** | 各自交易时段内 10~30s，非交易时段 30min | 10s | 夜盘（美股）默认**不轮询**，改为进入 App 时刷新 + 每小时一次 |
| 分时（trends2） | 进入详情页时拉取，日内每 60s | 30s | 页面不可见即停 |
| K 线（kline） | 首次全量 + 每日增量 | 12h | 复权参数变化时重拉 |
| 盘中估值 | 60s | 30s | 本地计算为主，行情复用 |
| 基金实时净值 | 15:00 后每 10min | 5min | 到 23:30 停止 |
| 基金历史净值 | 每日 1 次增量 | 6h | 冷启动首次分页回填 |
| 上金所金价（官方） | 交易时段 60s | 30s | 分时 + 日线 |
| **浙商银行金价** | 用户主动刷新 / 每日 1 次 | 当日有效 | 抓包方案限 ≤1 次/15min |
| 季报持仓 | 每季度检查 / 手动刷新 | 7d | |
| 交易日历 | 每年 1 次 | 30d | 内置降级表 |

保护措施：
1. **单源优先级 + 多源降级**：东财 → 腾讯 → 新浪（同一语义的行情）
2. **令牌桶限流**：全局 ≤ 5 req/s，单域名 ≤ 2 req/s；统一 `RequestThrottler`
3. **指数退避 + 熔断**：连续 5 次失败 → 该源静默 10 分钟
4. **请求合并**：`instrument` 批量接口（`ulist.np/get?secids=a,b,c`）
5. **离线优先**：UI 永远先渲染本地缓存，再后台刷新（stale-while-revalidate）
6. **可配置请求头**：UA/Referer 集中管理，便于接口变更时一处修改

> 实测提示：连续高频请求后会出现空响应（软限流），因此**必须有退避 + 缓存**，不能裸轮询。

### 6.4 存储容量估算

| 数据 | 单条 | 规模 | 合计 |
|---|---|---|---|
| 基金日净值 | ~60 B | 200 只 × 20 年 × 250 | ~60 MB |
| 行情快照（压缩后） | ~40 B | 50 标的 × 240 点/日 × 3 年 | ~150 MB |
| 每日组合快照 | ~200 B | 10 年 × 2 账户 | <2 MB |
| 交易流水 | ~150 B | 10 年 5000 笔 | <1 MB |
| 估值运行记录 | ~80 B | 100 只 × 240/日 → 收盘压缩 | ~20 MB/年 |
| 海外行情/金价分钟线 | ~40 B | 20 标的 × 240 点/日 × 90 天（定时清理） | ~17 MB |

策略：行情分钟级快照**仅保留 30 天**，之后降采样为 5 分钟/日线；净值与快照永久保留。

## 7. 小米 / HyperOS 适配（本产品的成败关键）

小米的后台管理是 Android 生态最激进的，必须"顺势而为"。

### 7.1 保活与省电

| 手段 | 实现 | 引导文案 |
|---|---|---|
| 自启动白名单 | 引导用户开启「设置 → 应用设置 → 授权管理 → 自启动」 | "不开启则收盘净值不会自动更新" |
| 省电策略 | 引导「电池 → 应用省电策略 → 无限制」 | 同上 |
| 最近任务锁定 | 提示下拉锁定卡片 | —— |
| 精确闹钟 | `AlarmManager.setExactAndAllowWhileIdle` + `SCHEDULE_EXACT_ALARM` 权限申请 | Android 12+ 需单独授权 |
| WorkManager 周期任务 | 15 min 最小周期，做兜底同步 | |
| 前台服务 | 盯盘时段（09:25–15:05）可选开启，常驻通知显示今日盈亏 | 用户显式开启，可随时关闭 |
| 息屏/重启恢复 | `BOOT_COMPLETED` 重建调度；开机后补一次全量增量同步 | |

**首次启动的「保活引导向导」**：4 步图文，逐步检测（用 `ActivityManager.isBackgroundRestricted()`、`PowerManager.isIgnoringBatteryOptimizations()`），全部可跳过，跳过时明确告知哪些功能会不准时。

### 7.2 通知

- 渠道分离：`实时动态(Live)` / `行情提醒` / `净值` / `计划` / `日报` / `前台服务`（重要性各不相同，见 §4.8）
- Android 13+ 首启申请 `POST_NOTIFICATIONS`，用"净值更新提醒"作为价值说明
- **灵动岛卡片**：主路径走 Android 16 Live Updates（AOSP 标准），HyperOS 焦点通知仅作增强，详见 §4.14
- 通知限频：单规则 ≤ 3 次/日，全局 ≤ 8 条/日，避免被用户关闭
- 提供通知诊断面板（最近 20 次触发记录 + 被拦截自查）

### 7.3 桌面小组件（Glance）

| 尺寸 | 内容 | 刷新 |
|---|---|---|
| 2×2 | 今日盈亏（大字 + 百分比） | 交易时段 15 min（受系统限制） |
| 4×2 | 总资产 + 今日/本月盈亏 + 迷你曲线 | 同上 |
| 4×4 | 前 5 只持仓简表 | 同上 |

> 系统小组件刷新受 WorkManager 15 分钟下限约束；若需秒级刷新只能依赖前台服务或用户点击。设计上**接受 15 分钟粒度**，点击进入 App 看实时。

### 7.4 隐私与安全

- 默认**不申请**：通讯录、短信、位置、存储（用 SAF）、电话状态
- 数据库 SQLCipher（密钥存 Android Keystore）；可选"生物识别解锁"（BiometricPrompt）
- 禁止 `adb backup`（`android:allowBackup="false"`），改用应用内加密导出
- 无广告 SDK、无三方统计 SDK（可内置本地埋点表）
- 隐私政策明确：**持仓数据不出设备**

### 7.5 上架与分发

| 途径 | 要求 | 风险 |
|---|---|---|
| 小米应用商店 | 软著、隐私政策、ICP/主体资质；**金融类 App 需资质核验**，涉及"证券投资咨询"表述会被驳回 | 高：需按"个人理财记账工具"定位，杜绝任何投资建议功能 |
| 应用宝/华为等 | 同上 | 高 |
| 自用分发 | 直接安装 APK（需允许"安装未知应用"）或 ADB | 低 |
| 内测 | 小米内测通道 / Firebase App Distribution 等价物 | 低 |

**建议**：P0~P1 阶段以自用 + 小范围内测为主；对外发布前做一次合规审查（见 §8）。

## 8. 合规与风险

### 8.1 红线

1. **不得提供投资建议**：不做买卖信号、不做"推荐基金"、不做收益预测承诺
2. **不得误导**：估值必须标注「估算值，非官方净值，仅供参考」，且展示历史误差
3. **数据版权**：东财/腾讯/新浪接口均为**未公开开放接口**，个人研究使用风险较低，**商用必须获得授权**或替换为持牌数据源（Wind/聚源/中证指数/上金所官方）
4. **不得代客理财、不得归集资金**、不做任何交易通道
5. 用户协议 + 免责声明首启弹出，可随时在设置中查阅

### 8.2 风险登记册

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 接口变更/失效 | 高 | 高 | 适配器抽象 + 多源互备 + 快速发版通道；关键接口每日健康检查 |
| 接口封禁 IP/UA | 中 | 高 | 限流、退避、缓存、可选自建代理 |
| 估值不准被误信 | 中 | 高 | 置信区间 + 精度面板 + 显著免责 |
| 小米杀后台导致数据延迟 | 高 | 中 | 多层保活 + UI 明确标注数据时间戳与"可能延迟" |
| 应用商店下架 | 中 | 中 | 定位为记账工具；自用分发兜底 |
| OCR 识别错误污染账本 | 中 | 中 | 强制人工确认 + 批次可撤销 + 审计日志 |
| 数据丢失（换机/损坏） | 中 | 高 | 每日自动本地备份（保留 7 份）+ 手动加密导出 |

- **动效**：数字变化用 `animateFloatAsState` 滚动；下拉刷新用 HyperOS 风格
- **手势**：持仓列表左滑 = 快速加仓/减仓；长按 = 编辑/删除；双指捏合切换图表粒度
- **暗色**：跟随系统 + 手动；纯黑模式（OLED 省电）
- **无障碍**：TalkBack 支持、字号缩放 200% 不破版、对比度 ≥ 4.5:1
- **快捷入口**：App 长按图标 → "记一笔/看估值/看黄金"；可接入小米负一屏/小爱同学快捷指令（P2）

## 12. 测试策略

| 层级 | 手段 | 重点 |
|---|---|---|
| 单元 | JUnit5 | 成本法、TWR、XIRR（对比 Excel 的 XIRR 结果）、交易日历边界 |
| 回测 | 自建 `EstimationBacktester` | 用历史净值 + 历史季报重演估值，输出 MAE/命中率 |
| 契约 | 数据源适配器集成测试（MockWebServer + 真实响应快照） | 接口字段变更立刻报警 |
| UI | Compose UI Test + Robolectric | 关键流程：记一笔、导入、切换日期 |
| 兼容 | 真机矩阵：小米 15/14/13、Redmi K80/Note14、MIX Fold、Pad | 后台保活、小组件、字体缩放、深色 |
| 时区 | 固定「假装现在」注入时钟 | 夏令时切换日、各市场开闭市边界、跨日净值归属（QDII T+1/T+2） |
| 提醒 | 历史数据回放 + 注入时钟 | 去抖不误报（噪声序列下 0 次触发）、升级触发、冷却与配额、跨日重置、静默时段、σ=0 边界 |
| 图表 | 快照测试 + 性能基准 | 降采样后曲线保形、1.5 万点渲染帧率、空数据/单点/断点渲染 |
| 性能 | Macrobenchmark | 冷启动、滚动、订阅刷新 |
| 数据完整性 | 每日自检 Worker | `sum(txn) == position` 断言，异常写 audit_log |
