## F.3 关键产品决策：不建模品类的诚实展示

**这是审计中最重要的产品结论。** 养基宝等产品对短债/同业存单也报一个"估算涨跌幅"，
但实测表明**模型误差大于信号**（0.87bp vs 0.64bp）—— 那个数字是**负价值**。

**正确做法**

| 品类 | 展示 | 文案 |
|---|---|---|
| 中长期纯债 | 估算涨跌幅 + 置信区间 | 「估算 +0.012% · 14:32 · 债券ETF+国债期货」 |
| **短债 / 同业存单** | **不显示涨跌幅数字**，显示状态 | 「今日预计 +0.02bp（按票息）· **短债波动极小，不提供盘中估算**」 |
| 货币基金 | 万份收益 + 7日年化 | 「万份收益 0.2210 · 7日年化 1.52%」 |
| 场内 ETF | 实时价格 + 折溢价 | 「¥8.472 (+0.34%) · 溢价 +0.12%」 |
| 银行积存金 | 买入/卖出价 + 来源 | 「买入 894.20 / 卖出 891.60 · **来源：截图校准 12:41**」 |
| 数据不可用 | `—` | 「暂无估算（数据源不可用）」 |

**红线**：**绝不为不可靠的品类编造数字**。这既是合规要求，也是与竞品的核心差异。

## F.4 必须补的估算分级设计（→ `docs/03 §B.12` + `docs/04`）

```kotlin
enum class EstimateGrade {
    EXACT,        // 场内实时价格，非估算            → 显示实价，无"估算"角标
    HIGH,         // R² ≥ 95%，MAE ≤ 0.1%          → 正常显示，弱化角标
    MEDIUM,       // R² 85~95%，MAE ≤ 0.6%         → 显示 + 置信区间
    LOW,          // R² < 85% 或 σ 大               → 显示 + "参考意义有限" + 显式误差
    NONE,         // 不建模品类（短债/同业存单）      → 🔴 不显示数字
    UNAVAILABLE,  // 数据源不可用                    → 显示 "—"
}
```

**路由规则（自动判定）**

```
1. 场内标的（有实时价格）                → EXACT
2. 指数/ETF联接/黄金联接（T0 命中）      → HIGH
3. 主动股票/混合（T1，rolling R² ≥ 95%） → HIGH / MEDIUM（按 20 日滚动 R² 动态）
4. 主动科技/主题（T1，R² 71~87%）        → MEDIUM / LOW
5. 债券（B5，改善 ≥ 30%）                → MEDIUM
6. 短债/同业存单/货币（判定为"不建模"）    → NONE
7. 源失败 / 无持仓数据 / 新基金 < 20 日   → UNAVAILABLE
```

**降级链**（每一级都要有 UI 表现）
```
T0 → T1 → T2季报穿透 → 零基线 → UNAVAILABLE
```
且在 UI 上明示当前处于哪一级（例如「基于季报持仓（8-15 披露）」）。
