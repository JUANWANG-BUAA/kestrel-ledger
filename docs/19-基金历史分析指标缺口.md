# 基金历史分析指标缺口

> 2026-10-18。对应代码：`FundProfile` / `FundNavEstimator` / `FundMoneyYieldEstimator` / `FundScreens.kt` / `FundDetailSheet`。本文只讨论“基金本身的历史表现”，不把个人持仓的 XIRR/TWR 混在一起。

## 1. 结论

当前基金详情回答的是“现在净值多少、盘中估算多少、最近 90 个点怎么走”，还没有回答：

- 这只基金**过去 1 个月/3 个月/1 年/3 年/成立以来**赚了多少？
- 年化收益是多少？和同类/基准比是赢还是输？
- 最大回撤多深、持续多久、现在离高点多远？
- 波动、夏普、卡玛、下行风险如何？
- 收益是靠什么来的：选股、行业、仓位、运气，还是风格暴露？
- 这些数字的数据是否完整、是否复权、是否扣费？

所以现在的“基金分析”本质上仍是**净值展示 + 盘中估算**，不是业绩分析。用户能看到一条线，但无法判断这只基金值不值得长期持有、风险是否匹配。

## 2. 当前已有与缺口

| 维度 | 当前已有 | 缺口 |
|---|---|---|
| 净值 | 单位净值、累计净值、净值日期、日涨跌 | 没有复权/分红调整后的收益序列 |
| 走势 | 最近 90 个点折线、首尾日期 | 没有基准、没有回撤、没有阶段收益 |
| 估算 | 指数/重仓回归、货币基金万份收益 | 只有“今天”，没有历史验证/滚动误差 |
| 持仓 | 最新披露重仓 10 只、权重 | 没有历史持仓，无法做风格漂移/归因 |
| 组合 | 组合 XIRR/TWR、回撤、配置 | 不是基金自身业绩，不能替代基金分析 |
| 数据 | 本机 120 个净值点、完整历史可手动补齐 | 默认样本不足 1 年；基准/同类数据未接入 |

**最关键的三个数据问题：**

1. **默认只有 120 个净值点**，约半年；1 年/3 年/成立以来年化、滚动收益、跨周期回撤都做不了。
2. **没有统一复权口径**：单位净值遇到分红/拆分会出现“假下跌”；必须用累计净值或复权净值，并明确标注口径。
3. **没有基准和同类**：只有一条基金线，用户无法判断“跌 20%”是市场不好还是基金经理不行。

## 3. 应纳入的指标

### 3.1 P0：没有这些，页面不能叫“业绩分析”

| 指标 | 定义/口径 | 数据要求 | 展示建议 |
|---|---|---|---|
| 区间收益 | 期末/期初−1，分别算 1M/3M/6M/1Y/3Y/5Y/成立以来 | 复权净值；至少覆盖区间 | 一行 period 表 |
| 年化收益 CAGR | `(期末/期初)^(365.25/天数)−1` | ≥1 年；不足 1 年只显示区间收益 | 与区间收益并列，不混用 |
| 最大回撤 | 历史峰值到后续谷值的最大跌幅，带起止日 | 完整净值序列 | 数字 + 起止日 + 修复天数 |
| 当前回撤 | 当前净值相对历史高点的跌幅 | 完整序列 | 与最大回撤同卡 |
| 年化波动率 | 日收益标准差 × √252 | ≥60 个交易日 | 风险卡 |
| 基准同期收益 | 跟踪指数/同类基准同区间 | 基准日线，交易日对齐 | 基金/基准/超额三列 |
| 超额收益 | 基金区间收益 − 基准区间收益 | 同区间、同币种 | 正负号 + 颜色 |
| 数据完整性 | 净值点数、起止日、缺失日、是否复权、基准覆盖 | 数据自检 | 顶部小 badge |

### 3.2 P1：让“收益”变成“风险调整后的收益”

| 指标 | 作用 | 注意 |
|---|---|---|
| 夏普比率 | 每单位总风险超额收益 | 无风险利率要显式假设；<60 样本不显示 |
| 索提诺比率 | 只惩罚下行波动 | 下行样本不足不显示 |
| 卡玛比率 | 年化收益 / 最大回撤 | 回撤为 0 或样本不足不显示 |
| 下行波动率 | 只统计负收益的标准差 | 与波动率并列 |
| 回撤修复天数 | 从谷值回到前高所需天数 | 未修复显示“仍在修复” |
| 正收益天数/月数占比 | 稳定性 | 区分日/月，不混算 |
| 最好/最差单日、单月 | 尾部体验 | 同时给日期 |
| 滚动 1 年收益胜率 | 任意时点持有 1 年的正收益比例 | 需要 ≥2 年历史 |
| 滚动 3 年收益分布 | 长期稳定性 | 样本不足不显示 |
| 连续下跌天数/最大连跌 | 持有体验 | 避免只给“最大回撤” |

### 3.3 P1：基准与主动能力

| 指标 | 定义 | 适用 |
|---|---|---|
| Beta | 基金对基准的敏感度 | 有明确基准 |
| Alpha（年化） | 回归截距年化 | 有足够样本；需标注回归窗口 |
| R² | 基准解释度 | 低 R² 时 Alpha 不可信 |
| 跟踪误差 | 超额收益标准差 × √252 | 指数基金/ETF 重点 |
| 信息比率 | 年化超额 / 跟踪误差 | 主动基金 |
| 上行/下行捕获率 | 基准上涨/下跌时基金的平均表现 | 需基准对齐 |
| 相关性 | 与基准/现有持仓的相关系数 | 组合重叠分析 |
| 风格暴露 | 大盘/中小盘、价值/成长、久期/信用 | 需要持仓/因子数据；当前只有最新重仓，先标注“未交付” |

### 3.4 P2：基金特有与持有体验

| 指标/信息 | 为什么重要 | 当前状态 |
|---|---|---|
| 管理费/托管费/申购赎回费 | 长期复利损耗；净收益口径 | 模型没有字段，需补数据源 |
| 基金规模/AUM | 规模过小有清盘风险，过大有容量约束 | 未接入 |
| 基金经理任期 | 历史业绩是否同一人创造 | 未接入 |
| 同类排名/百分位 | 绝对收益不等于相对优秀 | 需要同类基金池，当前没有 |
| 最大回撤修复时间 | 比“回撤多深”更影响持有体验 | 可算，未接 |
| 股债/行业/地区配置 | 解释收益来源 | 只有最新披露重仓，缺历史 |
| 换手率/风格漂移 | 判断策略是否稳定 | 需要历史持仓/半年报，当前没有 |
| ETF 折溢价/流动性 | 场内买入成本 | 有 listed price comparison，未纳入业绩页 |
| 货币基金 7 日年化/万份收益 | 货币基金不能用净值涨跌 | 有万份收益估算，未做历史年化 |
| 压力情景 | 利率+100bp、权益−20%、黄金−10% | 没有 |

## 4. 公式与防御

```text
区间收益   = endNav / startNav - 1
年化收益   = (endNav / startNav) ^ (365.25 / days) - 1
日收益     = nav[t] / nav[t-1] - 1
年化波动   = std(dailyReturns) * sqrt(252)
最大回撤   = min(nav[t] / runningPeak[t] - 1)
夏普       = (年化收益 - riskFree) / 年化波动
索提诺     = (年化收益 - riskFree) / 下行波动
卡玛       = 年化收益 / abs(最大回撤)
跟踪误差   = std(fundReturn - benchmarkReturn) * sqrt(252)
信息比率   = 年化超额 / 跟踪误差
Beta       = cov(fund, benchmark) / var(benchmark)
Alpha      = 年化(mean(fund) - beta * mean(benchmark))
```

必须带防御：

- **不足 1 年不年化**，只显示“区间收益”；
- **少于 60 个交易日不显示夏普/波动**；
- **最大回撤只用完整序列**，并在旁边写“自 X 至 Y”；
- **分红/拆分必须复权**，否则收益率和回撤都会错；
- **基准必须同币种、同交易日历**；QDII 要处理时差/海外假日；
- **同类排名没有同类池就不显示**，不要用“全市场排名”冒充；
- **基金收益 ≠ 投资者收益**：基金页显示净值口径；个人页显示 XIRR/TWR，两者不能混。

## 5. 页面怎么放

不要把 20 个指标一次堆出来。建议基金详情分三层：

1. **首屏结论**：近 1 年收益、年化、最大回撤、基准超额；四个数字 + 数据日期。
2. **业绩与风险**：period 表（1M/3M/6M/1Y/3Y/成立以来；基金/基准/超额），下面一行最大回撤/波动/夏普/卡玛。
3. **展开分析**：净值 vs 基准、回撤水下曲线、滚动 1 年胜率、年度收益、持仓集中度/费用/规模（有数据才显示）。

空态要具体：

- “仅 120 个净值点，暂不能计算 1 年/3 年年化；补齐完整历史后可看。”
- “基准日线覆盖 0/120 天，暂不显示超额。”
- “成立不足 1 年，不展示年化。”

## 6. 实施拆分

| 工作包 | 内容 | 验收 |
|---|---|---|
| FUND-ANALYTICS-01 | 全量净值历史 + 复权口径 + 数据完整性对象 | 1/3/5 年样本可用；单位/累计净值口径明确 |
| FUND-ANALYTICS-02 | `FundPerformanceAnalytics` 纯 domain：区间/年化/回撤/波动/夏普/索提诺/卡玛 | 确定性单测；边界样本返回“不可用”而非 0 |
| FUND-ANALYTICS-03 | 基准对齐：跟踪指数/同类基准、交易日历、QDII 时差 | 基金/基准/超额三列；缺失显示原因 |
| FUND-ANALYTICS-04 | 基金详情 UI：业绩表、风险卡、回撤水下曲线、净值 vs 基准 | 首屏 4 个结论；展开不拥挤；深浅色正常 |
| FUND-ANALYTICS-05 | 滚动收益/年度收益/胜率/捕获率 | 2 年以上样本；不足时隐藏 |
| FUND-ANALYTICS-06 | 费用/规模/经理/同类排名/持仓历史 | 有数据才显示；无数据明确“未接入” |
| FUND-ANALYTICS-07 | 压力测试/风格漂移/归因 | 研究口径，不进入默认首屏 |

**优先级**：01 → 02 → 03 → 04 先做；05/06 随后。没有 01/03，02 算出来的数字不可信；没有 02，04 只是把错误数字画得更好看。
