## C.0 设计原则（决策时优先此表）

| # | 原则 | 具体含义 | 反例（禁止） |
|---|---|---|---|
| 1 | **一屏知全局** | 资产首屏不滚动即可看到：总资产、今日盈亏、持有盈亏、数据时间 | 首屏塞 5 个卡片把盈亏挤出屏幕 |
| 2 | **数字优先** | 等宽数字（tabular）、千分位、显式正负号、涨跌色语义一致 | 数字跳动、靠颜色区分正负而无符号 |
| 3 | **来源可信** | 每个数字长按可看：来源、时间戳、口径（官方/估算/折算） | 只给一个数，不说是谁的 |
| 4 | **估算可见** | 估算值与官方值必须视觉可分（虚线/半透明/角标/斜体数字） | 估算值与官方值长得一样 |
| 5 | **三次可达** | 任一功能从首页 ≤3 次点击 | 分析功能藏在 5 层菜单里 |
| 6 | **单手可及** | 主操作（记一笔、刷新、切换区间）放在屏幕下 1/3 | 顶部右上角放大按钮 |
| 7 | **离线不空** | 无网也有数据，只标注"数据截至 xx" | 转圈白屏 + "网络错误" |
| 8 | **不打断** | 无广告、无弹窗促销、无强制登录、无全屏引导墙 | 启动插屏广告 |

## C.1 设计 Token

### C.1.1 色彩（语义化，涨跌色可切换）

| Token | 亮色 | 暗色 | 纯黑模式 | 用途 |
|---|---|---|---|---|
| `color.up` | `#E64545` | `#FF6B6B` | 同暗色 | 上涨（默认 A 股习惯） |
| `color.down` | `#12A55A` | `#34D07A` | 同暗色 | 下跌 |
| `color.flat` | `#8A8F98` | `#9AA0A6` | 同暗色 | 平盘 |
| `color.estimate` | `#8B5CF6` | `#A78BFA` | 同暗色 | **估算值专用**（紫，非涨跌色） |
| `color.bank` | `#D4A017` | `#E8C15A` | 同暗色 | 银行金价（金色系） |
| `color.stale` | `#F5A524` | `#FBBF5C` | 同暗色 | 数据延迟/降级/缓存 |
| `color.bg` | `#F5F6F8` | `#0B0C0E` | `#000000` | 页面背景 |
| `color.surface` | `#FFFFFF` | `#16181C` | `#0A0A0A` | 卡片 |
| `color.surfaceAlt` | `#F0F1F4` | `#1E2126` | `#111111` | 次级容器/输入框 |
| `color.text.primary` | `#14161A` | `#E8EAED` | 同暗色 | 主文本 |
| `color.text.secondary` | `#6B7280` | `#9AA0A6` | 同暗色 | 次要文本/单位 |
| `color.divider` | `#EDEFF2` | `#23262B` | 同暗色 | 分割线 |
| `color.accent` | `#FF6A00` | `#FF8534` | 同暗色 | 主色（呼应 HyperOS） |
| `color.accentContainer` | `#FFF1E6` | `#3A2313` | 同暗色 | 主色容器 |

**规则**
- 涨跌色**只用于**表达涨跌，绝不用于装饰（避免误读）
- 涨跌方向可在设置切换为「涨绿跌红」，切换后所有图表同步
- 色盲友好：涨跌除颜色外**必须**同时有符号（`+`/`−`）或箭头
- 动态取色（Material You）只影响 `accent`，**不得**污染 `up/down/estimate`

### C.1.2 字体阶梯（sp）

| 名称 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 40/48 | 600 等宽 | 总资产大字 |
| `headline` | 28/36 | 600 等宽 | 关键数字（今日盈亏、金价克价） |
| `title` | 18/26 | 600 | 卡片标题、页面标题 |
| `body` | 15/22 | 400 | 正文、列表主文本 |
| `label` | 13/18 | 500 | 标签、按钮 |
| `caption` | 12/16 | 400 | 来源、时间、免责声明 |
| `micro` | 10/14 | 500 | 图表刻度、角标 |

**规则**：所有数字用等宽字形（`FontFeatureSetting("tnum")`）；金额与百分比禁止换行折行；单位字号比数字小 2 级且用 `text.secondary`。

### C.1.3 间距 / 圆角 / 阴影 / 动效

| 类别 | 值 |
|---|---|
| 间距栅格 | 4dp；常用 4 / 8 / 12 / 16 / 24 |
| 页面左右边距 | 16dp；平板 24dp |
| 卡片圆角 | 16dp；小组件 24dp；标签 999dp（胶囊） |
| 卡片阴影 | 亮色 `elevation 0 + 1dp border(#EDEFF2)`；暗色无阴影靠描边 |
| 动效时长 | 微 120ms / 常规 200ms / 页面 300ms |
| 缓动 | `cubic-bezier(0.2, 0, 0, 1)`（Material 3 emphasized） |
| 数字滚动 | 300ms `animateFloatAsState`，仅当变化 ≥ 1 个单位 |
| 列表项入场 | 禁止（避免滚动卡顿）；只允许删除/新增的单条动画 |

**要点**
- 金额 ↔ 份额**双向联动**（改一个另一个自动算），避免用户手算

- **实时预览**（保存前就算出对持仓/收益率的影响）→ 这是本产品的高价值细节
- 保存后 Snackbar 提供「撤销」（5 秒内可撤，符合原则 8）

## C.4 状态设计（每个页面都必须定义）

| 状态 | 表现 | 规则 |
|---|---|---|
| 首次空态 | 插画 + 一句话 + 主按钮 | 「还没有持仓」→ `[手动记一笔] [截图导入]`，禁止只显示"暂无数据" |
| 加载中 | 骨架屏（形状匹配内容） | 禁止全屏转圈；超过 400ms 才显示骨架 |
| 局部刷新 | 顶部细进度条 / 数字旁小圆圈 | 不遮挡已有内容（stale-while-revalidate） |
| 离线 | 顶部黄色条「已离线 · 显示 10-14 数据」 | 内容照常渲染 |
| 数据延迟 | 数值旁 `⚠︎ 延时` 角标 | 点击说明延迟原因 |
| 单源失败 | 静默降级到备源 | 不打扰用户，只写 `sync_log` |
| 全部失败 | 卡片级错误态 + `[重试]` | 只影响该卡片，不整页报错 |
| 接口变更（解析失败） | 卡片显示「数据格式变化，已反馈」+ 自动降级 | 写诊断包，供快速修复 |
| 权限缺失 | 内联提示条 + `[去开启]` | 不做阻断式弹窗 |
| 无数据（合法） | 显示 `—` | 不要显示 0（0 是有效值） |
