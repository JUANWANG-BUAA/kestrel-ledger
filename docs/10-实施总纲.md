### H.3.1 存储架构（一句话）

> **手机端 SQLCipher 单库为主，冷热分层 + 定期压缩；PCF 原始数据只留 90 天，但合成指数永久保留。**

**压缩策略（关键）**

| 策略 | 效果 |
|---|---|
| **PCF 原始数据只留 90 天**，只保留 `pcf_synthetic_index` | 22 MB/年 → **5 MB** |
| 盘中快照 30 天后降采样为日线 | 480 KB/日 → 0 |
| 估值记录收盘后压缩为 `(收盘估值, σ, 最大偏差)` | 2 MB/日 → ~50 KB/日 |
| 分钟线 90 天后删除（日线已够用） | 360 KB/日 → 0 |
| 历史净值用 **delta 压缩**（只存变化） | 省 30~40% |

### H.3.4 数据分级与加密

| 级别 | 数据 | 存储 |
|---|---|---|
| **L1 公开** | 行情、净值、PCF、季报 | 明文（可放缓存表，可清空重建） |
| **L2 敏感** | 持仓、流水、成本、金额、自选、提醒 | **SQLCipher 加密库**（密钥 → Android Keystore） |
| **L3 机密** | 备份包、导出文件 | **Argon2id 派生密钥 + AES-GCM**，口令不落盘 |

**日志与诊断脱敏**：金额/份额默认替换为 `***`；诊断包**默认不含**持仓（用户显式勾选才含结构、永不含金额）。

### H.3.5 备份与迁移

| 项 | 设计 |
|---|---|
| 自动备份 | 每日 04:00，本地加密包，**保留 7 份** |
| 手动导出 | 用户设口令（≥8 位）→ SAF 保存到自选位置 |
| 恢复 | 口令解密 → SHA-256 校验 → 预览"将导入 N 条流水" → 确认 → **跑一致性自检** |
| 迁移前 | **schema 变更前自动备份**（保留 3 份） |
| 多设备（P2） | 端到端加密，服务端只存密文，密钥由口令派生 |

**备份内容**
```
backup_<ts>.mkt (zip, AES-GCM)
├─ db.sqlite.enc        主库
├─ settings.json        设置（含提醒规则、标定参数）
├─ pcf_synthetic.json   PCF 合成指数（轻量但重算成本高）
├─ manifest.json        版本/schema/条数/SHA-256
└─ README.txt           恢复说明 + 免责声明
```

### H.3.6 一致性与自检
