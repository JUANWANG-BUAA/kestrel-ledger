## I.3 🔴 归档算法（最欠开发）

### I.3.1 问题一：**前复权价格的「历史漂移」**（已实测确认）

**事实**：腾讯 `fqkline` 的 `qfq` 参数**未生效**（实测 qfq ≡ raw，因子恒为 1.0000）。

**后果**：所有因子回归都在用**不复权价**，除权日产生假跳空。

**已实测到的真实案例**：

| 标的 | 除权日 | 前收 | 当日收 | 假跌幅 | 实际分红 |
|---|---|---|---|---|---|
| 工商银行 | **2023-07-17** | 4.87 | 4.57 | **−6.16%** | 每股派 0.3035 元 |

**为什么归档会漂移**：前复权以「最新价」为基准，每次分红都会**改写全部历史值**。
→ 同一日期在不同时间抓到不同的价格 → **训练集不可复现**。

**正确设计（量化数据工程标准做法）**

```
┌─ 存什么 ────────────────────────────────────────┐
│  raw_price     不复权价（永远不变）              │
│  adj_factor    复权因子（只在分红/拆股日变化）    │
│  div_cash      每股现金分红                       │
│  div_date      除权日                             │
└──────────────────────────────────────────────────┘

用时动态计算（不存储复权价）：
  前复权价 = raw × adj_factor / adj_factor_latest
  后复权价 = raw × adj_factor
  真实日收益 = raw_ret 与 dividend 修正：
      r = (P_t + div_t) / P_{t-1} − 1        ← 除权日必须加回分红
```

**归档策略**：存 **raw + adj_factor**（两者都是 append-only，永不改写）→ 天然可复现。

### I.3.2 问题二：降采样算法（未实现）

| 场景 | 算法 | 关键要求 |
|---|---|---|
| 分钟线 → 日线 | OHLCV 聚合 | high=max、low=min、volume=sum、需处理缺失分钟 |
| 分时（240 点/日）→ 5 分钟（48 点） | **LTTB**（Largest-Triangle-Three-Buckets） | 保形不抖动；已设计未实现 |
| 估值运行记录 → 每日摘要 | 收盘/最大/最小/σ | 30 天后压缩 |
| 组合快照 → 月/年 | 末值 + 极值 + 累计收益 | 保留极值日期 |

**LTTB 实现要点**

```kotlin
// 240 点 → 48 点，保持视觉特征（峰谷不被抹平）
fun lttb(points: List<Pair<Long, Double>>, threshold: Int): List<Pair<Long, Double>>
// 1. 分桶：bucketSize = (n-2) / (threshold-2)
// 2. 首尾点固定保留
// 3. 每桶选一点，使与「前一点+下桶均值」构成三角形面积最大
fun triangleArea(a: Point, b: Point, c: Point): Double =
    abs((a.x - c.x) * (b.y - a.y) - (a.x - b.x) * (c.y - a.y)) * 0.5
```

### PR5 设计（EWMA，比 GARCH 更适合移动端）

```
σ²_t = λ·σ²_{t-1} + (1−λ)·r²_{t-1},   λ = 0.94（RiskMetrics 标准）
区间宽度 = z × σ_t × √(1 + 1/T)      （含参数不确定性）
输出：当 σ_t > 近60日均值×1.5 时，UI 自动显示"今日波动偏大，估值误差可能扩大"
```

## I.10 第六轮交付（已实现）

### I.10.1 ✅ 复权因子修正（归档算法）

**发现的问题**：腾讯 `fqkline` 的 `qfq` 参数**实测未生效**（qfq ≡ raw，因子恒为 1.0000）
→ 全部分析在用**不复权价** → 除权日产生假跳空。

**实测污染证据**：

| 标的 | 除权日 | 原始（错误） | 修正后 | 差 |
|---|---|---|---|---|
| 工商银行 | 2023-07-17 | **−6.16%** | +0.07% | 6.23pp |
| 工商银行 | 2024-07-16 | **−5.00%** | −0.06% | 4.94pp |
| 五粮液 | 2024-07-12 | +1.38% | **+5.45%** | 4.06pp |
| 贵州茅台 | 2024-06-19 | +0.75% | **+2.97%** | 2.23pp |

**实现**：`tools/adjust.py` + `stock_dividend` 表（**1823 只标的 / 24,835 条分红记录**）

```
真实收益 r = (P_t + cash_per_share) / P_{t−1} − 1         （含送转时再乘 (1+bonus+it)）
归档原则：存**不复权价（append-only）+ 分红表** → 任意时点可复现
         禁止存前复权价（每次分红都会改写全部历史）
```

**诚实评估**：除权日占总观测的 **0.401%**，单点误差最大 3pp，
但对**平均 MAE 的改善 ≈ 0%**（0.744% 的样本 × 3pp ≈ 0.02pp，被淹没在 0.6% 的 MAE 里）。
→ **这是数据正确性修复，不是精度提升**；价值在于**可复现性**与**单日极端误差**。

### I.13.4 ✅ 缺口④ Brinson 归因（`tools/brinson.py`）

三因子 Brinson-Fachler：`超额 = 配置效应 + 选择效应 + 交互效应`

数据：组合行业权重（`holding_industry` 聚合）+ 行业收益（**PCF 合成指数**）+ 沪深300 基准

**实测 110022 易方达消费 2025Q3**：
```
基金 +8.87%   基准 +17.70%   超额 −8.84%
配置效应 −2.96%（超配食品饮料 51%，该行业仅 +6.31%，而基准 +17.70%）
→ 结论：跑输源于**行业配置**（踏错风格），而非选股
```

⚠️ **已知局限**：① 季报持仓不完整（全量持仓可缓解）② 行业分类用东财口径
③ 基准行业权重采用等权近似（真实需中证行业数据）④ 修复了一个 bug：
