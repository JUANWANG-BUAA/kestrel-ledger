## G.3 本轮的两个新诊断（很有信息量）

### G.3.1 同类基金残差高度同步 → 误差是"系统性"的，不是噪声

| 分组 | 组内残差相关系数 | 含义 |
|---|---|---|
| **黄金联接（3 只）** | **0.977** | 误差几乎完全一致（都跟踪同一标的，模型缺失信息相同） |
| **AI 主题（3 只）** | **0.761** | 高度同步（同赛道、同滞后季报） |
| 可转债（5 只） | 0.316 | 中等 |
| 债券（8 只） | 0.313 | 中等 |
| 科技成长（6 只） | 0.130 | 弱 |
| **指数联接（6 只）** | **0.087** | 几乎独立（各自跟踪不同指数） |

**这个排序本身就是证据**：越是"共享同一批持仓"的基金，误差越同步。
→ **误差来自共同的缺失信息（滞后持仓、缺失因子），而不是随机噪声。**
→ **结论：补数据 > 换方法。**

### G.3.2 残差 ACF(1) 为负 → 存在均值回归，但幅度不足以利用

| 分组 | ACF(1) |
|---|---|
| 黄金联接 | **−0.246** |
| 指数联接 | −0.081 |
| 可转债 | −0.063 |
| 债券 | +0.064 |
| 科技成长 | +0.031 |
| AI 主题 | +0.023 |

负 ACF 说明残差有反转特征，理论上可用 `−λ·resid(t−1)` 修正。
**但实测无效**（最优 λ 恒为 0）——因为反转幅度小于残差噪声本身。
