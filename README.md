# 养基助手（代号 Market）

> Android 原型已交付基金／黄金本地流水、账户现金、持仓核算、日周月事实报告、行情自选、行业/概念板块和数据健康页。当前代码使用 SQLCipher 加密本地账本，并以 Android Keystore 封装数据库密钥；首次升级会把既有 SQLite 账本导出到临时加密库，校验后再切换。设备上的旧库迁移与故障恢复尚未完成运行验收。新导出的备份文件另用用户密码加密。实现进度以 [`docs/13`](docs/13-首版产品与量化验收收口.md) 和 [`docs/14`](docs/14-全量优化任务清单.md) 为准，产品规划与数据源研究不代表 Android 功能已交付。

本机命令行构建需要 JDK 21 和 Android SDK 35；若默认 `java` 是 JDK 27，请在构建命令前设置 `JAVA_HOME` 与 `ANDROID_HOME`。Debug APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`。新安装会创建 SQLCipher 加密账本；升级会尝试无损迁移既有明文 SQLite 库，只有临时库校验通过后才切换。数据库密钥由本机 Android Keystore 密钥封装，应用云备份已关闭。旧库迁移、中断恢复和设备密钥异常仍需在设备上完成验收。新导出的备份文件经过用户密码加密，旧版明文备份仅为迁移兼容而允许导入。在设备验收完成前，请保留独立加密备份，不要把此原型作为唯一的敏感资产记录。

产品目标是小米手机上的**个人基金 / 黄金 / 全球市场助手**，覆盖本地记账、收益核算、基金估值、黄金对比、全球行情、可视化与简报；当前 Android 落地范围以实现状态文档为准。

> 产品原则：默认不上传持仓、不需要账号、不做交易、不给投资建议。数据库加密已进入实现，旧库迁移仍待设备验收；导出的新备份使用用户密码加密。

## 技术栈一句话

当前 Android 工程使用 Kotlin 2.1、Jetpack Compose Material 3、`:app`/`:domain`/`:data` Gradle 模块、SQLCipher SQLiteOpenHelper 和 WorkManager。`:domain` 已接入非 QDII 指数型基金与已披露联接 ETF 的 60 日回归和滚动样本外分级；场内基金详情独立展示精确交易价与最近公布净值；货币基金以万份收益而非单位净值展示近 7 个公布日滚动参考。主动股票/混合已接入披露 A 股重仓池 OLS T1：只有前复权历史、当日行情、重仓覆盖和滚动样本外表现均达门槛时才显示回归值，否则回退到明确标为低质量的披露重仓即时参考。指数与 T1 残差已接入 SQLCipher 持久化和 90% 目标经验区间；不足 60 个残差样本或最近 20 个留出样本覆盖低于 80% 时隐藏区间。组合风险模块已接入账户 TWR 序列上的年化波动、Sharpe/Sortino、1 日 95% 历史 VaR/CVaR 和持仓收益相关性；波动/比率需 60 个有效日、尾部损失需 250 个有效日，风险参数可本机配置并显示保存时点。跨市场节假日日历与长周期样本验收仍待完成。非指数债券路由仍未接入，T1 样本表现与真机区间覆盖验收待完成。Hilt、Room、Glance 和 ML Kit OCR 仍属于后续计划，不应视作当前依赖或已交付功能。

黄金持仓已支持标准 `GOLD.SGE.AU9999` 按上金所元/克行情计价；匹配代码且名称标为 ETF 的 A 股行情可在资产页绑定，基金代码 `518880` 默认绑定对应元/份行情。资产页可按持仓代码从东方财富动态获取场内报价；只有返回名称标为 ETF 的同代码报价会进入账户估值。来源和源报价时点会进入加密账本并用于持仓盈亏与当日组合快照。自定义银行黄金资产可记录银行买入/回购价、银行卖出价、12/24/48/72 小时有效期及最近报价历史，持仓按用户卖出时可得的回购价估值；报价过期后市值与新组合快照会标为不可用，历史报价保留。国际金价只用于行情对照，不自动推算银行价格。数据库 v20 与备份 v7 保存银行双向报价和报价绑定，旧 v1-v6 备份仍可导入；设备验收待完成。

分析页可选择一项通用参考指数；选择保存在本机，指数日线按需刷新并缓存数据源。周/月报告展示指数价格收益，账户 TWR 可用时再计算相对超额，指数价格收益不含股息，也不代表个性化基准。报告另外汇总自然周期内已确认且未冲正的买卖手续费与分红代扣税；完整时点加权资产与行业归因仍在开发。数据库当前版本 v21，扩展行情日线的数据源字段；加密备份仍为 v7。

## 红线（不可妥协）

1. 不提供投资建议、不做交易通道、不承诺收益
2. 估值一律标注「估算，非官方」，并展示历史误差与置信区间
3. 持仓数据默认不出设备；OCR 全本地
4. 不模拟登录第三方平台抓取持仓（合规与风控风险）
5. 所有行情必须携带来源与时间戳（`source` / `quality` / `asOf`）
